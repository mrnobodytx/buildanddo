# Icons

Lucide 0.469.0 outline icons, copied verbatim from `lucide-static` (ISC licence), the same version as the app's `lucide-react`. Each file strokes `currentColor`, which renders black inside an `<img>`; in code, use the `Icon` component or inline the SVG so it inherits `foreground`, `stage-foreground` or the state colour. Use 20px in controls, 14–16px beside small text, always next to a word.
