# ContentUse

Who is using the broadcaster's content: per item, people and agents as one stacked bar with a 2px gap, the total at the end, and how it was used.

Intentional addition. **Consumer provides:** `items` `[{title, humans, agents, how}]` (`how` e.g. *12 classes · 4 embeds · 9 citations*), optional `period`, `note`.

- People are `chart-human`, agents `chart-agent`, with a legend; the total is text, never inside the bar.
- Count uses, not views. An agent use is a research, improvement or verification run.
