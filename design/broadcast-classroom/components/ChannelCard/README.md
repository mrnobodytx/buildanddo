# ChannelCard

A broadcast listing: status, transport, title, host, and the measured audience while on air.

Intentional addition for the channel list. **Consumer provides:** `title`, `host`, `status`, `transport`, `level`, optional `summary`, `href` (the whole card becomes the link), `viewers` (measured), `when` (scheduled).

- Live channels read *On air*; scheduled ones show when.
- No audience count unless measured: *Audience unmeasured*.
