# Architecture — DARPA Semantic ISR

Status: executable public reference workload, with measured trials generated by the shared runner.

## Purpose and implemented method

Make the bandwidth/reconstruction tradeoff of selective semantic updates measurable at the protocol level before coupling it to video detectors and edge hardware.

The sender encodes either complete scene annotations or quantized relevant-object deltas with periodic keyframes and explicit removals. The receiver parses the actual JSON bytes, enforces sequence order, clears state on keyframes and applies updates/removals. Relevant-object recovery and coordinate error are compared with frame truth.

## Data and control flow

1. Validate opportunity.yaml and experiment.yaml; match the exact fixture digest.
2. Freeze Twelve synthetic annotated frames, ten objects per frame, changing relevance and a six-frame keyframe interval.
3. Run two candidates over seeds 17, 29 and 43 with two repetitions per seed.
4. Preserve Actual wire bytes, packets and reconstructed scene history; byte ratio, relevant-object recall and coordinate error.
5. Recompute descriptive statistics from all successful complete seed groups.
6. Verify evidence bytes before generating a self-contained review package.

## Reproducibility and limits

The run records code/input fingerprints, interpreter version, command, seed,
start/finish, elapsed time, return code and artifact digests. Computational replay
excludes timing and Python allocation peaks. All retained performance is a local
observation; requirement satisfaction needs separately scoped reviewed evidence.

Relevance labels are supplied truth. JSON packet savings are not video compression performance, detector accuracy, a radio demonstration, physical feasibility or DP2 qualification.

## Extension boundary

Attach current official requirements and DP2 qualification evidence. Establish real EO/video datasets and detector outputs, compare against conventional video codecs, then measure reconstruction utility, latency and power on declared hardware.

No private runtime, live provider, credential, account, physical deployment or
external submission is created by this architecture.
